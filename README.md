# Balance Waste — ระบบบริหารจัดการของเสีย (Waste Management)

**บริษัท เทพวัฒนา จำกัด** (ทะเบียนโรงงานเลขที่ 820200300125423 · หนังสือ สก.2 เลขที่ 2569-12560 · ปี 2569 — ตั้งไว้ที่ `COMPANY` ต้น `apps-script/Code.gs`)

ใช้ลงข้อมูลปริมาณของเสียที่จัดเก็บในโรงงาน: เลือกประเภทของเสีย กรอกน้ำหนัก (**ตัน**) และภาชนะบรรจุ (ถัง 200 ลิตร / IBC / Bigbag)
แล้วติดตามยอดคงเหลือ การส่งกำจัด และการใช้โควตาตามปริมาณที่ได้รับอนุญาต

- รีโป: https://github.com/watanathep8-dotcom/balance-waste-thepwatana
- หน้าเว็บ: GitHub Pages จากโฟลเดอร์ `docs/` → https://watanathep8-dotcom.github.io/balance-waste-thepwatana/
- Backend: Google Apps Script (`apps-script/Code.gs` ไฟล์เดียว) เก็บข้อมูลใน Google Sheets

## ความสามารถ

| หน้า | รายละเอียด |
|---|---|
| แดชบอร์ด | KPI (คงเหลือรวม, จัดเก็บเดือนนี้, ส่งกำจัดปีนี้, % โควตา), เกจเข็มโควตารวม, วงแหวนโควตาแยกประเภท, กราฟ 12 เดือน, โดนัทภาชนะ, โควตาตามผู้รับ, แจ้งเตือน, รายการล่าสุด |
| บันทึกจัดเก็บ | เลือกประเภท (ค้นหาได้ แยกตามผู้รับ) · น้ำหนัก **ตัน** (ทศนิยม 2 ตำแหน่ง เช่น 0.25) ปุ่มลัด +0.1 / +0.5 / +1 / +5 / +10 ตัน · ภาชนะ + จำนวน · สถานที่จัดเก็บ · หมายเหตุ · โหมด **ยอดยกมา** สำหรับของที่มีอยู่ก่อนเริ่มใช้ระบบ |
| ส่งกำจัด / นำออก | แสดงยอดคงเหลือสด · ส่งเกินยอดคงเหลือ/จำนวนภาชนะไม่ได้ · เลขที่ใบกำกับการขนส่ง · ทะเบียนรถ |
| ข้อมูลภายใน (ล็อกด้วยรหัสผ่าน) | รายการที่จัดการภายในโรงงานเอง (บำบัดเอง) — ตัดยอดคงเหลือเหมือนส่งกำจัด แต่ **ไม่นับโควตา สก.2** · ทุกคนเห็นเมนู แต่ต้องใส่รหัสผ่านก่อนเปิด: รายการ `TR-…` (วันที่ ระบบ/วิธีการ หมายเหตุ ผู้บันทึก) ส่งออก Excel และฟอร์มบันทึก · ปุ่ม **ล็อก** บนหน้านี้ |
| คงเหลือ & โควตา | คงเหลือ = รับเข้า − ส่งกำจัด − บำบัดเอง, ภาชนะในคลัง, % โควตาปีนี้ (เตือน ≥ 80 %, เกิน > 100 %), อายุล็อตเก่าสุด (FIFO, เตือนเกิน 90 วัน), สรุปตามผู้รับ, ยอด “บำบัดเองสะสม” แยกประเภท |
| ประวัติรายการ | ตัวกรอง (ประเภท, รายการ, ช่วงวันที่, ผู้รับ, ค้นหา), ส่งออก Excel (CSV UTF-8 BOM, น้ำหนักเป็นตัน), แก้ไข / ลบ (ถามรหัสผ่านผู้ดูแลระบบเมื่อกด) |
| บันทึกประวัติ (Log) | ทุกการกระทำ ใคร ทำอะไร เมื่อไร (รหัสผ่านผู้ดูแลระบบ) |
| ตั้งค่าประเภทของเสีย | (ผู้ดูแลระบบ) **ผู้รับดำเนินการ**: เพิ่ม / แก้ไขชื่อ-เลขทะเบียน-รหัสจัดการ (ไม่บังคับ) / ปิดใช้งาน / ลบ (เมื่อไม่มีประเภท) พร้อมจำนวนประเภทและโควตารวม · **ประเภทของเสีย**: เพิ่ม / แก้ไข (รหัส, ชื่อ, ปริมาณอนุญาต (ตัน ทศนิยม 2 ตำแหน่ง), รหัสการจัดการ, เลือกผู้รับจากรายการหรือ "+ เพิ่มผู้รับรายใหม่", เปิด/ปิดใช้งาน, ลบเมื่อยังไม่มีรายการ) — ที่เพิ่มไว้จะขึ้นในโควตาตามผู้รับ / โควตาแยกประเภท ฟอร์มบันทึก-ส่งกำจัด ยอดคงเหลือ ประวัติ และ CSV อัตโนมัติ · ประเภทหรือผู้รับที่มีรายการแล้วให้ปิดใช้งานแทนการลบ · ปุ่มรีเซ็ตข้อมูล (รหัสผ่านผู้ดูแลระบบ + ใส่รหัสอีกครั้งตอนรีเซ็ต) |

### เว็บเปิดใช้ได้ทุกคน — ล็อกเฉพาะ “ข้อมูลภายใน” และเครื่องมือผู้ดูแล

- **ไม่ต้องเข้าสู่ระบบ**: ทุกคนเปิดเว็บแล้วเห็นแดชบอร์ด คงเหลือ & โควตา ประวัติรายการ และบันทึกจัดเก็บ / ยอดยกมา / ส่งกำจัด ได้เลย (ต้องตั้ง **ชื่อผู้ใช้งานที่มุมขวาบน** ก่อนบันทึก — ชื่อถูกบันทึกเป็น “ผู้บันทึก” ทุกรายการ)
- **แดชบอร์ดเหมือนกันทุกคน** รวมการ์ด “ของเสียทั้งหมดในระบบ (สะสม)” = **บำบัดเอง** + ส่งกำจัด (ตัดโควตา) + คงเหลือ และกราฟ 12 เดือน (ยอดรวมเท่านั้น ไม่มีรายการ `TR-` รายตัว)
- เมนู **ข้อมูลภายใน** ต้องใส่รหัสผ่าน 3 ระดับ:

| ระดับ | Script Property | ทำอะไรได้ |
|---|---|---|
| ดูได้อย่างเดียว | `WASTE_VIEW_PASSWORD` | เปิดข้อมูลภายใน ดูรายการ / รายละเอียด / ส่งออก Excel (บันทึกไม่ได้) |
| พนักงานกรอกข้อมูล | `WASTE_STAFF_PASSWORD` | ดู + บันทึกข้อมูลภายใน (ฟอร์ม) |
| ผู้ดูแลระบบ | `WASTE_RESET_PASSWORD` | ทุกอย่าง: ดู / บันทึกข้อมูลภายใน, แก้ไข / ลบทุกรายการ, ตั้งค่าประเภทของเสีย, บันทึกประวัติ (Log), รีเซ็ตข้อมูล |

- รหัสผ่านที่ใส่เป็นตัวกำหนดระดับ (ถ้าตั้งรหัสเดียวกันสองระดับ จะได้ระดับที่สูงกว่า — ควรตั้งให้ต่างกัน) · ใส่รหัสครั้งเดียวต่อแท็บ อยู่ได้ 12 ชั่วโมง หรือจนกด **ล็อก** / ปิดแท็บ · เปลี่ยนรหัสผ่านระดับใด การปลดล็อกของระดับนั้นจะหลุดทันที
- เซิร์ฟเวอร์ตรวจสิทธิ์ **ทุกคำสั่ง** (ไม่เชื่อหน้าเว็บ): รายการ `TR-…` รายตัวส่งให้เฉพาะคำขอที่มีรหัสผ่าน (ระดับใดก็ได้) · บันทึกข้อมูลภายในต้องเป็นพนักงานกรอกข้อมูลขึ้นไป · แก้ไข / ลบ / ตั้งค่า / Log / รีเซ็ต ต้องเป็นผู้ดูแลระบบ
- ใส่รหัสผิด: หน่วง 1 วินาทีต่อครั้ง · ผิด 5 ครั้งต่อเบราว์เซอร์ หรือ 30 ครั้งรวมทุกคน ภายใน 15 นาที → ล็อกการใส่รหัส 15 นาที (แท็บที่ปลดล็อกอยู่แล้วใช้งานต่อได้)
- **ถ้า Property ใดยังไม่ได้ตั้ง ระดับนั้นจะใส่รหัสปลดล็อกไม่ได้** (`setupSystem()` แจ้งใน log ว่ายังขาดตัวไหน)
- หน่วย: หน้าเว็บกรอกและแสดงผลเป็น **ตัน** (ทศนิยม 2 ตำแหน่ง ใส่คอมมาคั่นหลักพัน) แต่ชีตยังเก็บเป็น **กก.** เหมือนเดิม (`weight_kg`) — เซิร์ฟเวอร์แปลง ตัน → กก. แบบตรงตัว (0.25 ตัน = 250 กก.) ข้อมูลเดิมที่มีเศษ กก. (เช่น 1,234.56 กก.) จะแสดงเป็น 1.23456 ตัน ไม่ปัดทิ้ง
- ข้อมูลภายใน: ทุกรายการยังบันทึกในชีต `movements` (kind `treat`, เลขที่ `TR-…`, คอลัมน์ `method`) และ Log เสมอ · ยอดคงเหลือที่แสดงเป็นยอดจริงเสมอ (รับเข้า − ส่งกำจัด − บำบัดเอง)
- เซิร์ฟเวอร์ตรวจยอดย้อนหลังทุกครั้ง (ส่งกำจัด / แก้ไข / ลบ): น้ำหนักของทุกประเภท และจำนวนภาชนะแต่ละชนิด ต้องไม่ติดลบ ณ เวลาใดเลย
- **ข้อมูลตั้งต้น (ปี 2569)**: ประเภทของเสีย 40 รายการ (อนุญาตรวม 1,101.55 ตัน) และผู้รับดำเนินการ 8 ราย มาจากไฟล์ `Waste_Summary_Report_Thepwatana_2569.xlsx` ชีต “รายการที่ได้รับอนุญาตทั้งหมด” (หนังสือ สก.2 เลขที่ 2569-12560) — ทุกบรรทัดเป็นคนละประเภท (รหัสเดียวกันที่ผู้รับ / รหัสจัดการต่างกัน เช่น 150110 เป็นคนละรายการ) · ฐานข้อมูลใหม่จาก `setupSystem()` จะมีข้อมูลนี้ให้เลย · ฐานข้อมูลที่สร้างไว้แล้วและยังว่าง ให้รัน `seedThepwatanaPermit()` **ครั้งเดียว** (ไม่เพิ่มซ้ำ — ถ้าชีต `waste_types` มีข้อมูลแล้วจะปฏิเสธและไม่แก้อะไร ไม่แตะรายการเคลื่อนไหว) · โควตาผู้รับแต่ละรายเท่าผลรวมของบรรทัดของผู้รับนั้น (เบตเตอร์ฯ 287.05 ตัน, อัคคีปราการ 209 ตัน — ชีต “สรุปโควตาตามผู้รับดำเนินการ” ในไฟล์รวมได้ 1,045.55 ตัน ต่างจากยอดอนุญาต 1,101.55 ตัน อยู่ 56 ตัน ระบบใช้ชีตรายการเป็นหลัก) · ผู้รับที่มีหลายเลขทะเบียน เก็บเลขแรกไว้ที่ผู้รับ ส่วนเลขของแต่ละบรรทัดอยู่ที่ประเภทของเสีย · ผู้ดูแลระบบแก้ไข / เพิ่มได้เองที่เมนู “ตั้งค่าประเภทของเสีย” ตามเดิม · “รีเซ็ตข้อมูล” คงประเภทและผู้รับไว้
- ระบบ **ไม่สร้างยอดคงเหลือให้เอง** — ของเสียที่จัดเก็บอยู่ก่อนแล้ว (เช่น น้ำล้างเครื่องจักร, ตะกอนบำบัดน้ำเสีย) ให้บันทึกเป็น “ยอดยกมา” ตามที่ตรวจนับจริง

## ติดตั้ง (ครั้งแรก)

1. สร้างโปรเจกต์ใหม่ที่ https://script.google.com ตั้งชื่อโปรเจกต์ **Balance Waste Thepwatana** แล้ววางเนื้อหา `apps-script/Code.gs`
   (และตั้งค่า `appsscript.json` ตามไฟล์ในรีโป: เขตเวลา Asia/Bangkok, V8)
2. **Project Settings → Script properties** เพิ่ม (ตั้งเอง ห้ามใส่ในโค้ด · ทั้ง 3 ค่าต้องไม่ซ้ำกัน):

   | Property | ค่า |
   |---|---|
   | `WASTE_VIEW_PASSWORD` | รหัสผ่านระดับ “ดูได้อย่างเดียว” (เปิดข้อมูลภายใน) |
   | `WASTE_STAFF_PASSWORD` | รหัสผ่านระดับ “พนักงานกรอกข้อมูล” (บันทึกข้อมูลภายใน) |
   | `WASTE_RESET_PASSWORD` | รหัสผ่านระดับ “ผู้ดูแลระบบ” (ใช้ยืนยันการรีเซ็ตข้อมูลด้วย) |

   `WASTE_SPREADSHEET_ID` ถูกสร้างให้อัตโนมัติโดย `setupSystem()` (ไม่ต้องตั้งเอง)
3. ในตัวแก้ไข Apps Script เลือกฟังก์ชันแล้วกด **Run**:
   - `setupSystem` — สร้างสเปรดชีต “Balance Waste Database” (ชีต `waste_types`, `receivers`, `movements`, `audit_logs` — ชีต `receivers` เดิมที่ยังไม่มีจะถูกสร้างและเติมจากประเภทของเสียอัตโนมัติเมื่อบันทึกครั้งแรก), ใส่ข้อมูลตั้งต้น 40 ประเภท / 8 ผู้รับ (เฉพาะสเปรดชีตที่สร้างใหม่) และบันทึก ID ไว้ใน Script Properties (รันซ้ำได้ ไม่สร้างซ้ำ)
   - `installKeepWarmTrigger` — (แนะนำ) ตั้ง trigger ทุก 10 นาที ให้ `keepWarm()` อุ่นแคชการอ่าน หน้าเว็บจะเปิดเร็วขึ้น
4. **Deploy → New deployment → Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. คัดลอก URL ที่ลงท้ายด้วย `/exec` ใส่ใน `docs/config.js`:

   ```js
   window.WASTE_CONFIG = { apiUrl: "https://script.google.com/macros/s/XXXX/exec" };
   ```
6. เปิด GitHub Pages ของรีโป `watanathep8-dotcom/balance-waste-thepwatana`: Settings → Pages → Branch `main` / folder `/docs`
   → https://watanathep8-dotcom.github.io/balance-waste-thepwatana/

ฟังก์ชันอื่นที่รันจากตัวแก้ไขได้: `clearReadCache()` (หลังแก้สเปรดชีตด้วยมือ), `removeKeepWarmTrigger()`

## ทดสอบ / ดูตัวอย่างในเครื่อง

```bash
node test/gas-mock.js                    # ทดสอบ backend + frontend ทั้งหมด (ไม่ต่อ Google)
node test/dev-server.js 8777             # เปิด http://127.0.0.1:8777/ ด้วย Apps Script จำลองในหน่วยความจำ (ฐานข้อมูลว่าง ไม่มีข้อมูลตั้งต้น)
node test/dev-server.js 8777 --demo      # เหมือนข้างบน + ประเภทของเสียและข้อมูลตัวอย่างที่สร้างขึ้น (ไม่ใช่ข้อมูลจริง)
```

dev-server ใช้รหัสผ่านจำลองเฉพาะในเครื่อง: `dev-view` / `dev-staff` / `dev-reset` (ไม่ใช่รหัสจริง)

## แยกข้อมูลจากเว็บ Balance Waste ของบริษัทอื่น

- ใช้ Apps Script project, สเปรดชีต และ Script Properties ของตัวเองทั้งหมด (ไม่มี ID / URL / อีเมลของระบบอื่นในโค้ด · `docs/config.js` เก็บ `apiUrl` ว่างจนกว่าจะ Deploy)
- เว็บอยู่โดเมนเดียวกัน (`watanathep8-dotcom.github.io`) กับเว็บอื่น จึงตั้งชื่อ key ใน browser ทุกตัวด้วย prefix `wthep_` (`wthep_user` ชื่อผู้ใช้, `wthep_client` รหัสเบราว์เซอร์สำหรับล็อกรหัสผิด, `wthep_sess` เซสชันของแท็บ, `wthep_rc:*` แคชการอ่านของแท็บ) — ไม่แชร์ localStorage / sessionStorage กับเว็บอื่น
- ฟังก์ชันที่รันจากตัวแก้ไข: `setupSystem()` (สร้างฐานข้อมูลใหม่ + ข้อมูลตั้งต้น), `seedThepwatanaPermit()` (เติมข้อมูลตั้งต้นลงฐานข้อมูลเดิมที่ยังว่าง — รันครั้งเดียว), `installKeepWarmTrigger()`, `removeKeepWarmTrigger()`, `clearReadCache()`
